📘 Descrição

Aplicação de console desenvolvida em C# (.NET) que consome a API pública ViaCEP para consultar informações de endereço a partir de um CEP informado pelo usuário.
O programa realiza uma requisição HTTP, interpreta o JSON retornado e exibe o resultado de forma organizada no terminal.

🚀 Funcionalidades

Entrada de CEP pelo usuário

Requisição à API ViaCEP (https://viacep.com.br/ws/{cep}/json/)

Tratamento de erros (CEP inválido, erro HTTP, exceções)

Exibição formatada das informações do endereço
